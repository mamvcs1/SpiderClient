## About

Spider Client is an Android application project featuring a
black-and-red interface and planned integration with the Xray
networking ecosystem.

The project is being developed under the GitHub username
`mamvcs1`.

## Project Status

This repository currently contains an initial Android project
structure and a prototype user interface.

Real Xray engine integration, VPN tunnel implementation,
connection lifecycle management, and complete device testing
must be completed separately.

## Technology

- Kotlin
- Android SDK
- Gradle
- libXray / Xray ecosystem
